# openf50-extra: plan

Spec: `docs/superpowers/specs/2026-10-05-openf50-extra-design.md`. TDD: each step's tests first (tests/ conventions:
stubs, every shell, `OPENF50_LIB=1`).

1. **PATH list** - `rootfs/overlay/opt/openf50/lib/path-commands` (+ openf50-ussd, sms, openf50-voice, openf50-extra);
   assemble.sh, build-rootfs.sh read it; test_static compares against the file.
2. **openf50-update extra core** - `EXTRA`, `EXTRAS`, `extra_installed`, `extra_release`, `extra_unpack NAME TARBALL`
   (validate name/bin, `.name.new` + rename), `extra_vpn_wanted ROOT`, `extra_adopt NAME ROOT`;
   `fetch_verified` honours `OPENF50_RELEASE_URL`. Tests in test_update.py.
3. **openf50-update apply/check** - extras to fetch (outdated installed + migration), download phase, install after
   the systems, adopt fallback; check lists extras. Test with a stubbed fetch_verified and a fake disk.
4. **openf50-extra** - list/status/install/remove/link/adopt, sources openf50-update for its functions;
   `OPENF50_EXTRA_FILE`, release choice. Tests (tests/test_extra.py) with a fake disk and a local release dir served
   through a curl stub.
5. **openf50-vpn** - engine paths (extra first, /opt/openf50/bin second), `engines` subcommand, missing-engine message,
   self-heal in `run`. Tests in test_vpn.py.
6. **Boot hooks** - rootfs-fixups calls `openf50-extra link`; OpenWrt openf50-post too. Toolkit "Turn on" installs.
7. **Images and release** - tools/make-extra.sh; assemble.sh/build-rootfs.sh drop the engines; make-release.sh builds
   the asset, sums, uploads, audit; install.sh --build.
8. **Installers** - android-install.sh: install pushed `openf50-extra-*.tar.gz`, adopt on update (marked block, tested);
   install.sh/install.ps1: question (default no), download with the release, push; i18n tr/zh; Pester test.
9. **Docs** - README VPN section + extras, tests/README.md, BUILD.md.
10. **Device** - U30 Air: build the payload, serve it from the Mac (`OPENF50_RELEASE_URL`), install, run the VPN from
    the extra, restore; F50 #1: `openf50-extra link`, openf50-ussd on the PATH of a non-login shell.
11. **Review** - self-review + an independent reviewer; fix; report.
